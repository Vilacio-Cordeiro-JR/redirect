# SCOACI — Sistema de Controle Operacional do Arquivo Corrente e Intermediário

Aplicação web e PWA (Progressive Web App) para redirecionamento seguro e controle de acesso a sistemas de arquivos.

## 🚀 Tecnologias

- **HTML5 / JavaScript ES6**
- **PWA (Progressive Web App)**
- **Vercel** (Hospedagem e Deploy Contínuo)

## 📲 Instalação como App Mobile

1. Acesse o sistema via navegador no dispositivo móvel.
2. No menu do navegador (ou no alerta de instalação automático), selecione **Adicionar à tela inicial** ou **Instalar aplicativo**.
3. O app **SCOACI** será instalado na gaveta de aplicativos e na tela inicial do smartphone.

## ⚙️ Deploy na Vercel

```bash
git add .
git commit -m "feat: configuracao PWA SCOACI"
git push origin main
```
